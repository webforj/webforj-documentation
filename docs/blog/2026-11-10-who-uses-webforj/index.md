## Prodin: a Swing ERP on the web {#prodin}

Prodin Business Solutions is a Dutch ERP software provider with over 45 years of experience. Its ERP system was built on a Java Swing architecture, and the task was to modernize it for a web-first world.

Prodin looked at low-code platforms, and at a Java backend combined with front-end frameworks like Angular and React. It chose webforJ. The reasons include reuse of existing Java-capable code, some of which had been written over two decades ago, and using Java across the whole stack instead of splitting work across technologies and teams.

How the project went:

- Prodin assembled a six-member Java development team, including junior and mid-level developers, to assist in the migration alongside its existing staff.
- Within four months, Prodin delivered its first web-based modules to customers.
- The first web modules shipped while reusing the existing Java codebase, which avoided a complete rewrite.
- Zero deployment was one of the reasons for the choice: updates roll out across the web without requiring end-user intervention.
- Prodin can now offer both on-premise and SaaS solutions.

In Prodin's words: "webforJ enabled us to deliver a fully web-based version of our ERP in just four months, all while reusing our existing Java codebase."

The full story is [Prodin's Journey to Web Modernization with webforJ](https://webforj.com/wp-content/uploads/2024/10/BASIS_SuccessStory_Prodin.pdf).

## The b+p survey project {#bp}

b+p Beratung und Personal is an established HR consulting firm in the southwest of Germany, founded in 1998. In fall 2023 it partnered with BASIS International to deliver an employee survey at the University of Saarland. The goal was to gather insights from over 500 employees across mobile and desktop devices within just two weeks.

b+p managed the overall project. BASIS International provided consulting and development capacity, and the custom solution was built with webforJ.

The requirements were:

- Support a large number of respondents across desktop and mobile.
- Comply with GDPR, with anonymized responses that are accessible only in aggregated form.
- Scale to handle thousands of concurrent users.

Over 500 employees were invited to take part, and the app handled the load with no noticeable performance degradation. Responses were anonymized before delivery to the university.

The full story is [Empowering Project Implementation Partners with webforJ for Employee Surveys](https://webforj.com/wp-content/uploads/2024/10/BASIS_SuccessStory_bp.pdf).

## What these projects have in common {#in-common}

Both are business apps, and both ran under real constraints. One had an existing codebase to keep, the other a two-week window and a privacy rule.

Prodin is the desktop modernization case. A Swing ERP system with Java logic written over a long period moved to the web without a rewrite, by a Java team. Our guide to [Swing to web migration](/blog/swing-to-web-migration) covers moving screens one at a time.

b+p is the custom app case. A standard survey tool wasn't the fit, so the team built a tailored app in Java that was developed and deployed in one environment.

Both projects show what we built the framework for. webforJ is the full-stack Java framework for business web apps, and you build the whole app, screens included, in Java. For the capabilities behind that, read our guide to the [full-stack Java framework](/blog/java-full-stack-framework).
