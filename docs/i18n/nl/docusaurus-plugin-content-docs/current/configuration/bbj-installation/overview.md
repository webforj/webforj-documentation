Verplaats bestaande projecten naar [BBjShip](/docs/configuration/bbjship/overview), dat webforJ-apps in BBjServices installeert, implementeert en uitvoert. [Bestaande projecten](/docs/configuration/bbjship/existing-projects) geeft de wijzigingen aan die een project moet ondergaan.
