:::danger Verouderd en zal worden verwijderd
Deze sectie beschrijft de webforJ install plugin. Het is verouderd en zal in een toekomstige release worden verwijderd. Begin geen nieuwe projecten met deze plugin. Verplaats bestaande projecten naar [BBjShip](/docs/configuration/bbjship/overview), dat webforJ-apps in BBjServices installeert, implementeert en uitvoert. [Bestaande projecten](/docs/configuration/bbjship/existing-projects) geeft de wijzigingen aan die een project moet ondergaan.
:::
