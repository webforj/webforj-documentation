:::danger Obsolète et sera supprimé
Cette section décrit le plugin d'installation webforJ. Il est obsolète et sera supprimé dans une prochaine version. Ne démarrez pas de nouveaux projets avec. Déplacez les projets existants vers [BBjShip](/docs/configuration/bbjship/overview), qui installe, déploie et exécute des applications webforJ dans BBjServices. [Les projets existants](/docs/configuration/bbjship/existing-projects) répertorient les modifications nécessaires à un projet.
:::
