Esta sección describe el plugin de instalación de webforJ. Está obsoleto y será eliminado en una futura versión. No comiences nuevos proyectos con él. Mueve los proyectos existentes a [BBjShip](/docs/configuration/bbjship/overview), que instala, despliega y ejecuta aplicaciones webforJ en BBjServices. [Proyectos existentes](/docs/configuration/bbjship/existing-projects) enumera los cambios que necesita un proyecto.
:::
