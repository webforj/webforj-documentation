:::danger Veraltet und wird entfernt
Dieser Abschnitt beschreibt das webforJ Installations-Plugin. Es ist veraltet und wird in einer zukünftigen Version entfernt. Beginnen Sie keine neuen Projekte damit. Migrieren Sie bestehende Projekte zu [BBjShip](/docs/configuration/bbjship/overview), das webforJ-Anwendungen in BBjServices installiert, bereitstellt und ausführt. [Bestehende Projekte](/docs/configuration/bbjship/existing-projects) listet die Änderungen auf, die ein Projekt durchführen muss.
:::
