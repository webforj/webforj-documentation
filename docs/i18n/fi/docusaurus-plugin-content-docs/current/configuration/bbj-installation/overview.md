Tässä osassa kuvataan webforJ-asennuspluginia. Se on vanhentunut eikä sitä enää käytetä tulevissa versioissa. Älä aloita uusia projekteja sen kanssa. Siirrä olemassa olevat projektit [BBjShip](/docs/configuration/bbjship/overview), joka asentaa, toimittaa ja suorittaa webforJ-sovelluksia BBjServicesissä. [Olemassa olevat projektit](/docs/configuration/bbjship/existing-projects) sisältää luettelon muutoksista, joita projekti tarvitsee.
:::
