<h2 className={styles.codeShowcaseTitle}>Everything is a Java class.</h2>

```java
@Route("/")
public class HomeView extends Composite<FlexLayout> {
  private TextField name = new TextField("What is your name?");
  private Button hello = new Button("Say hello");

  public HomeView() {
    hello.setTheme(ButtonTheme.PRIMARY)
         .addClickListener(e -> Toast.show("Hi, " + name.getValue() + "!"));

    getBoundComponent().add(name, hello);
  }
}
```
